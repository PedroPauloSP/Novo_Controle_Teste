Seu projeto usa principalmente:
* MVC 
* Arquitetura em Camadas 
* Repository Pattern 
* Service Layer Pattern 
* Dependency Injection 
* REST API Architecture 
É exatamente a estrutura profissional mais usada com Spring Boot para construir APIs REST.
Usamos padrões de projeto porque eles resolvem problemas comuns de forma organizada, reutilizável e profissional.
Na prática, os padrões ajudam a:
* organizar o código 
* facilitar manutenção 
* evitar repetição 
* reduzir bugs 
* melhorar escalabilidade 
* facilitar trabalho em equipe
